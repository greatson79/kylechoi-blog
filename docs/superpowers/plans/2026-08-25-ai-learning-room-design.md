Kyle Choi Notes 안에 `/learn/` 전용 학습자료실을 만들고, 주인님이 제공한 외부 학습 링크 5건을 빠짐없이 찾고 열 수 있게 한다.

## 사용자 흐름

1. 사용자는 글로벌 내비게이션의 `Learning`을 눌러 `/learn/`에 진입한다.
2. 상단 소개에서 이 페이지가 AI 활용 자료를 목적별로 모은 곳임을 확인한다.
3. 다섯 개의 학습 카드에서 제목과 한 줄 설명을 읽는다.
4. 카드 전체 또는 `자료 열기`를 누르면 해당 외부 자료가 새 탭에서 열린다.

- 외부 링크 안내: 모든 자료가 `jinminlee.com`에서 새 탭으로 열린다는 사실을 명시
- 글로벌 `Footer`

## 시각 원칙

- 참조 페이지의 큰 제목, 넓은 여백, 카드 단위 탐색 구조만 차용한다.
- 기존 블로그의 Pretendard, 색상 토큰, 컨테이너 폭, 헤더·푸터를 그대로 사용한다.
- 375px에서는 1열, 768px 이상에서는 2열 카드로 배치한다.
- 카드 전체가 하나의 링크이며 키보드 초점과 hover 상태를 동일하게 제공한다.
- 이미지와 장식용 아이콘은 추가하지 않는다. 콘텐츠 식별에는 제목과 텍스트만 사용한다.
