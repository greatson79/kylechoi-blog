> 구글 생태계에서 Gemini를 처음 쓰는 분을 위한 **실전 가이드**. 잘 묻는 법(프롬프트 4요소), 구글 도구 안에서 바로 쓰는 법(Workspace), 이미지까지 만드는 법(Nano Banana)을 **따라 하며** 익힙니다.
> 대상: 개인 무료 Gemini. 읽는 법 — 개념 → 따라하기 → 복붙 프롬프트 → 사례 → 미션. ※ 2026년 6월 기준, 구글 공식 문서 근거.

## 1.1 프롬프트 4요소 — 구글의 표준 공식

구글 공식 권장 4요소: **페르소나(Persona) · 작업(Task) · 맥락(Context) · 형식(Format)**.

- **페르소나**: 취할 관점/역할. "나는 프로젝트 매니저야."
- **작업**: 시킬 행동. "프로젝트 트래커를 만들어줘."
- **맥락**: 배경. "웹사이트 리뉴얼 프로젝트를 위한."
- **형식**: 출력 모양. "날짜·상태·작업 칸이 있는 표로."

→ 합치면: **"나는 프로젝트 매니저야. 웹사이트 리뉴얼 프로젝트를 위한 상세 트래커를 만들어줘. 날짜·상태·작업 필드가 있는 간단한 표로."**

### 실전 팁 (구글 공식)

- **자연어·완전한 문장으로**: 사람에게 말하듯.
- **구체적 + 반복**: 무엇을(요약/작성/톤 변경/생성) 원하는지 명확히. 안 되면 이어서 다듬기.
- **적당한 길이**: 잘 되는 프롬프트는 평균 **약 21단어**. 보통은 9단어 미만으로 너무 짧게 → 더 구체적으로.
- **`@`로 파일 참조**: 사이드 패널에서 `@문서이름`으로 Docs·Sheets를 불러와 맥락 제공.
- **페르소나 실험**: "동료처럼" vs "교사처럼" 비교.

### Before / After

- ❌ "보고서 써줘" (3단어)
- ✅ "나는 중소기업 마케터야. 신제품 출시 결과를 팀장에게 보고할 1페이지 요약을, 핵심 성과 3가지 불릿 + 표 1개로, 정중한 존댓말로 써줘."

### 복붙 템플릿

```text
[페르소나] 나는 ___야.
[작업] ___해줘.
[맥락] ___을 위한 / 대상은 ___.
[형식] ___ 형식으로, 분량은 ___.
```

## 1.2 Google Workspace 실전 — 앱별 활용

Gemini는 **사이드 패널(Ask Gemini)**로 구글 앱 안에서 바로 도와줍니다.

**Google Docs** — Help me write(초안·아웃라인), 요약, 톤·문장 개선. → 우측 Ask Gemini "이 주제로 3문단 초안" → "더 짧게/표로".

**Gmail** — 메일을 열고 우측 상단 **Ask Gemini** → 요약. "정중히 거절하는 답장 3문장"으로 답장 초안.

**Google Slides** — 텍스트 상자에서 '제목 쓰기/작성 도움', 새 슬라이드·이미지 생성, Drive 파일 참조.

**Google Drive** — 문서·PDF를 열지 않고 요약·핵심 추출.

### 실전 워크플로우 예시

> 회의록(Docs) → "핵심 결정·할 일로 요약" → 그 요약으로 Gmail "팀 공유 메일 초안" → Slides "3장 슬라이드로".
> ⚠️ 개인 무료와 유료 Workspace는 제공 기능이 다를 수 있습니다(일부는 유료 우선). 내 화면 기준으로 익히고, 안 보이면 gemini.google.com에서 시도.

## 1.3 이미지 생성(Nano Banana) 실전

현재 이미지 생성은 **'이미지 만들기(Create images, 일명 Nano Banana)'** 도구. (※ 과거 'Imagen' → 현재 Gemini 네이티브 이미지 모델.)

### 따라하기

1. 도구 메뉴 → **'이미지 만들기'**.
2. 모델 선택(Fast/Thinking/Pro) 후 프롬프트, 또는 편집할 이미지 업로드.
3. "색을 ***로", "더 단순하게", "텍스트만 ***로"로 이어서 수정.

> ⚠️ 무료는 **제한된 횟수(쿼터)**. 초과 시 더 단순한 모델로 전환·제한될 수 있고, 유료는 더 많은 횟수.

### 이미지 프롬프트 공식 — 주제 + 스타일 + 구도 + 용도 + (정확한 텍스트)

```text
워크숍 안내용 썸네일. 미니멀 플랫 일러스트, 파란 계열,
가운데 큰 제목 공간. 정확한 텍스트: "AI 워크숍". 1:1 정사각형.
```

```text
카페 신메뉴 홍보 이미지. 따뜻한 감성 사진 느낌, 라떼 클로즈업,
오른쪽 하단 여백에 텍스트 공간. 인스타 카드용 4:5.
```

만든 이미지는 다운로드해 Slides·Docs에 삽입.

## 활용 사례

- **소상공인**: 메뉴 설명(Docs) + 홍보 이미지 + 고객 답장(Gmail)을 한 자리에서.
- **교사**: 수업 자료 초안(Docs) → 슬라이드 자동 생성 → 삽화.
- **직장인**: 긴 메일·문서를 Ask Gemini로 30초 요약.

## 자주 막히는 점 & 해결

- 밋밋함 → 4요소 넣고 더 구체적으로(21단어 기준).
- 엉뚱한 추가 → "이 문서/자료에 있는 내용만 근거로".
- 이미지 글자 깨짐 → "정확한 텍스트: ___" 명시, 글자 적게.
- 기능이 안 보임 → 무료/유료 차이. gemini.google.com에서 시도.

## 실습 미션 ✍️

**미션 1 — 4요소 프롬프트**: 업무 요청을 페·작·맥·형으로 다시 써(20단어 이상) 짧은 버전과 비교.

**미션 2 — 앱 연결**: Docs 요약 → Gmail 답장 초안까지 한 흐름으로.

**미션 3 — 이미지**: 공식(주제+스타일+구도+용도+텍스트)으로 1장 생성, 2번 수정 후 Slides 삽입.

**미션 4 — @참조**: 사이드 패널에서 `@문서`로 내 파일 참조해 질문.

> 한 줄 정리: 초급은 **4요소로 잘 묻고, 구글 앱 안에서 바로 쓰고(@참조), 이미지까지 만드는** 단계입니다. 다음 단계(중급)에서는 나만의 AI 비서 **Gems**를 만듭니다.
