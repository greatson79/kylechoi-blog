> 대상: 비개발 파워유저. 1~3번에서 만든 프롬프트 자산·자동화·스킬을 **데이터와 연결된 라이브 워크플로우**로 합치고 캡스톤(Capstone)으로 마무리합니다.
>
> ⚠️ 라이브·스케줄·커넥터는 유료 플랜의 Cowork 기능입니다(기능별 플랜 조건은 아래 각 항목 참조). 2026년 7월 공식 안내 기준.

## 0. 이 페이지의 목표

부분들을 하나의 운영 시스템으로 묶습니다: 프롬프트 자산(1번) + 자동화·커넥터·스케줄(2번) + 스킬(3번) + **라이브 대시보드**.

## 1. 라이브 아티팩트를 커넥터와 통합 운영

중급에서 라이브 대시보드 설계를 배웠습니다. 고급에선 이를 **실제 데이터 소스와 묶어 상시 운영**합니다.

- 연결 앱(캘린더·업무 도구·시트)에서 데이터를 끌어와 갱신. 열 때 연결 앱의 데이터를 확인하되, **짧은 캐시가 있어 매번 최신이 보장되지는 않으며**, 최신을 강제하려면 아티팩트 헤더의 새로고침 버튼을 사용합니다.
- 전용 'Live artifacts' 탭에 보관, 수정 시 버전 저장(비교·복원).

## 2. 스케줄과 결합 — 갱신을 자동화

라이브 대시보드 + 스케줄 작업을 결합하면 **'가만히 둬도 도는' 시스템**이 됩니다. 예: 매일 오전 7시 스케줄이 데이터를 정리 → 대시보드가 최신 반영 → 아침에 열기만. (스케줄은 클라우드에서 원격 실행되어 컴퓨터가 잠들거나 Desktop 앱이 닫혀 있어도 정해진 주기에 돕니다. 로컬 파일·앱이 필요한 작업만 로컬에서 실행됩니다. Cowork 전 유료 플랜 — Pro·Max·Team·Enterprise.)

## 3. 데이터 권한·안전 (반드시)

- 커넥터 자동 사용: 라이브는 승인한 커넥터를 **매번 묻지 않고** 사용 → 읽기 전용 위주로 설계.
- 쓰기 권한 커넥터는 의도치 않은 수정 위험 → 꼭 필요한 곳만.
- 공유 범위: 라이브 아티팩트 공유는 **Team·Enterprise 플랜에서 조직 내 공유**가 가능합니다(Pro·Max에서는 공유·게시 불가). 계획에 맞게 공유 범위를 설계하세요.
- 민감정보를 넣지 않기.

## 4. 실제 자동화 사례

- 아침 브리핑 / 업무 트래커 / 주간 지표 대시보드 / 시장·경쟁 모니터. 공통 패턴: 목적 정의 → 소스 선택 → 항목 최소화 → (스케줄) → 권한·안전 점검.

## 5. 캡스톤(Capstone) — 엔드투엔드 자동화 🏁

> 고급의 졸업 작품. 내 실제 업무 하나를 처음부터 끝까지 자동화해 보세요.

과제: 반복 업무 하나를 다음 4요소로 엔드투엔드 구성.

1. 프롬프트 자산(1번): 핵심 프롬프트 + 평가 기준.
2. 프로젝트/스킬(3번): 맥락은 프로젝트, 절차는 스킬.
3. 자동화(2번): 커넥터 + 멀티스텝 + (가능하면) 스케줄.
4. 라이브 대시보드(4번): 결과·상태 보기.

산출물: ① 워크플로우 설계도 ② 커넥터·권한 표 ③ 안전 점검 체크리스트 ④ 평가 기준.

## 6. 미션 ✍️

**미션 1**: 캡스톤(Capstone) 업무의 4요소를 한 장의 흐름도로(클로드에게 다이어그램 아티팩트로 그려달라고 해도 됩니다).

**미션 2**: 커넥터별 읽기/쓰기 권한과 위험·완화책 표.

**미션 3**: 월 1회 운영 점검 항목 5가지(프롬프트 갱신·권한 재확인·결과 품질 등).

> 한 줄 정리: 고급의 완성은 **프롬프트 자산 + 자동화 + 스킬 + 라이브 대시보드를 하나의 운영 시스템**으로 묶고, 권한·안전을 설계하고, 캡스톤(Capstone)으로 엔드투엔드 자동화를 직접 만드는 것입니다.

이로써 초급(쓰는 법) → 중급(설계) → 고급(운영·자동화)의 여정을 마칩니다.
