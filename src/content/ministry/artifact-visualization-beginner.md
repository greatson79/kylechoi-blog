> 지금까지는 'AI가 글로 답하게' 했습니다. 이번엔 AI가 차트·다이어그램·표·작동하는 페이지 같은 '결과물 자체'를 만들게 하는 법을 배웁니다. 코딩을 몰라도, 말로 부탁하면 됩니다.

> ⚠️ 기능 범위는 업데이트로 바뀔 수 있습니다. 이 문서는 2026년 6월 기준입니다.

## 1. 아티팩트란 무엇인가요?

**아티팩트(Artifact)**는 클로드가 대화 '옆 창'에 따로 띄워 주는 독립된 결과물입니다. 코드, 글 문서, 표, 차트, 다이어그램, 작동하는 작은 웹페이지까지 — 대화에 묻히지 않고, 보고 편집하고 발전시킬 수 있는 별도 작업물로 나타납니다.

> 💡 비유: 일반 답변이 "말로 설명해 주는 것"이라면, 아티팩트는 "옆 화이트보드에 직접 그려서 보여주는 것". 보면서 "여기 색 바꿔줘", "이 항목 빼줘"라고 바로 고칠 수 있습니다.

핵심 장점은 **말보다 보여주는 게 빠른 것**을 보여준다는 점. 복잡한 절차, 수치 비교, 구조 관계는 글보다 그림 한 장이 낫습니다.

## 2. 무엇을 시각화할 수 있나요?

- **차트/그래프** — 막대·선·원형. 예: "이 매출 데이터를 월별 막대그래프로."
- **다이어그램** — 순서도·구조도·관계도. 예: "회원가입 절차를 순서도로."
- **표** — 항목 정리·비교. 예: "세 요금제를 기능별로 비교하는 표로."
- **인터랙티브 위젯/미니앱** — 계산기, 체크리스트 같은 간단한 도구.
- **문서·HTML 페이지** — 보고서, 한 장짜리 안내 페이지 등.

> 코딩 지식이 없어도 됩니다. **무엇을 보여주고 싶은지**만 말하면 형태는 클로드가 만듭니다.

좋은 시각화 요청 요령: 데이터·내용을 함께 주기, 종류를 지정하기, 용도(발표·보고)를 알리기.

## 3. 라이브 아티팩트 — 살아 있는 결과물

일반 아티팩트는 만든 순간의 모습으로 고정. **라이브 아티팩트(Live Artifact)**는 열 때마다 최신 데이터를 다시 불러와 갱신되는 '살아 있는' 페이지입니다. (Claude Cowork 기능)

표 비교:

| | 일반 아티팩트 | 라이브 아티팩트 |
|---|---|---|
| 데이터 | 만든 시점에 고정 | 열 때마다 최신으로 갱신 |
| 위치 | 그 대화 안에 있음 | 전용 'Live artifacts' 탭에 따로 보관 |
| 재방문 | 그 대화를 찾아가야 함 | 탭에서 바로 다시 열기 |
| 기록 | — | 수정마다 버전 저장, 이전 버전 복원 |
| 데이터 출처 | 대화에 준 내용 | 연결된 앱·로컬 파일에서 실시간 |

연결한 앱(캘린더·업무 도구·스프레드시트)에서 데이터를 끌어와 대시보드·트래커·요약 페이지를 한 번 만들어두면, 다음에 열 때 '오늘 기준 최신 상태'로 다시 채워집니다.

**활용 예**: 아침 브리핑(오늘 일정+할 일), 업무 트래커, 주간 지표 대시보드.

**알아둘 점**

- 라이브 아티팩트는 유료 플랜(Pro·Max·Team·Enterprise)의 Claude 데스크톱 앱(Cowork)에서 제공.
- 현재는 내 기기에 저장(다른 기기로 따라오지 않음), 공유는 아직 준비 중.
- 만들 때 승인한 연결 앱을 매번 묻지 않고 사용 — 데이터를 바꿀 수 있는 연결은 주의.

## 4. 무엇을 언제 쓰나요?

- 한 번 보여주면 되는 것(자료 안 그림, 발표용 차트, 설명용 순서도) → **일반 아티팩트**
- 계속 들여다보며 최신 상태가 중요한 것(대시보드, 트래커, 매일 보는 브리핑) → **라이브 아티팩트**

## 5. 실습 미션 ✍️

**미션 1 — 차트 만들기**: 아무 숫자 데이터(예: 최근 5개월 지출)를 주고 "월별 막대그래프 아티팩트로" 요청 → "색을 파란 계열로"로 한 번 수정.

**미션 2 — 다이어그램 만들기**: 내 업무·일상의 한 절차를 "순서도로 그려줘".

**미션 3 — 라이브 아티팩트 설계**: 매일/매주 반복해 보고 싶은 정보를 대시보드로 만든다면 들어갈 항목 3가지를 적으세요.

> 한 줄 정리: 아티팩트는 클로드가 '옆 창에 띄워 주는 결과물'입니다. 보여주는 게 나은 것은 차트·다이어그램·표로, 매번 최신이 중요한 것은 라이브 아티팩트로 만들어 계속 재사용하세요.
