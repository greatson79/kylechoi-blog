> 초급에서 잘 묻고 구글 도구에서 쓰는 법을 익혔습니다. 중급에서는 **나만의 AI 비서(Gems)**를 직접 만들고, 이미지·데이터 작업을 **실전 워크플로우**로 굳힙니다.
> 대상: 개인 무료 Gemini. 구조 — 개념 → 따라하기 → 복붙 프롬프트 → 사례 → 미션. ※ 2026년 6월 기준, 구글 공식 문서 근거.

## 2.1 Gemini Gems 페르소나 설계 (실전 제작)

**Gems(젬)**는 지시와 자료를 한 번 세팅해두는 **나만의 맞춤형 Gemini**입니다.

### 따라하기 (개인 무료)

1. **gemini.google.com → 'Gems 탐색(Explore Gems)' → '새 Gem(New Gem)'**.
2. **이름** 입력.
3. **지시(instructions)**: 목표·원하는 행동·선호 형식.
4. (선택) **Knowledge(지식)** → **파일 추가**: 브랜드 가이드·샘플 등.
5. 오른쪽 **미리보기** 테스트 → **저장(Save)**.

> 💡 프리메이드 Gem으로 시작 가능. 지시가 막막하면 Gemini에게 "이 목적의 Gem 지시문을 작성·보완해줘"(메타프롬프팅).

### 좋은 지시문 구조 — 복붙 템플릿

```text
[역할] 당신은 ___입니다.
[대상] 주 독자/고객은 ___입니다.
[톤·문체] ___ 톤, ___ 문체.
[형식] 기본 출력은 ___ 형식.
[제약·금지] 항상 ___, 절대 ___ 금지.
[예시] 좋은 결과 예: ___
[자료] 첨부 지식 우선, 없는 내용은 추측 금지.
```

### 사례

- **블로그 작가 Gem**: Knowledge에 과거 잘 쓴 글 2~3편 → 지시 "이 문체를 따라, 도입부는 질문, 마무리는 행동 유도" → 이후 "이번 주제 ___" 한마디로 초안.
- **이메일 정중화 Gem**: "거친 초안을 정중한 비즈니스 톤으로, 핵심 유지, 5문장 이내."

## 2.2 워크플로우 모듈화 및 이미지 파이프라인

만능 Gem 하나보다 **작고 집중된 Gem 여러 개**가 잘 작동합니다(블로그 초안 / 이메일 정중화 / 회의록 요약). 같은 **톤 규칙**을 각 Gem에 넣어 균일하게.

### 이미지 파이프라인 (따라하기)

1. **브랜드 스타일 가이드 문구** 정리: "플랫 일러스트, #1A73E8 파란 계열, 흰 배경, 굵은 산세리프 제목."
2. 첫 이미지에 이 문구를 붙임.
3. 다음 장부터 **"이전 이미지와 같은 스타일로, 텍스트만 ___로"** → 시리즈 톤 통일.

> ⚠️ 개인 무료에서 **조직 공유 Gem**은 제한될 수 있습니다(Workspace 기능). 개인 Gem을 표준 템플릿처럼 재사용. 조직 배포는 심화 '확장'.

## 2.3 기초 데이터 분석 (Sheets + Gemini) — 실전

Sheets의 **'Ask Gemini'**로 자연어로 데이터를 다룹니다(공식: 트렌드·이상치·핵심을 빠르게).

### 무엇을 할 수 있나 (공식)

- **분석·인사이트**: "이 표에서 추세·이상치·핵심 3가지."
- **표·차트 생성**: "월별 막대그래프", "필요한 표를 만들어줘."
- **수식·정리**: "전월 대비 증감률 수식", "빈칸·중복 정리 방법."
- **Fill with Gemini(자동 채우기)**: 맞춤 텍스트 생성, **데이터 분류**, 요약, 구글 검색 기반 실시간 정보.

### 따라하기

1. Sheets에서 **'Ask Gemini'** 클릭.
2. "이 매출 표에서 가장 빠르게 성장한 카테고리 3개와 이유 추정."
3. "결과를 새 시트에 표로."
4. **Fill with Gemini**로 '카테고리' 열 자동 분류.

### 복붙 프롬프트

```text
이 표의 핵심 추세 3가지와 주의할 이상치를 불릿으로. 근거 셀도 표시해줘.
```

```text
A열의 고객 문의를 '환불/배송/제품문의/기타'로 분류해 옆 열에 채워줘.
```

> ⚠️ AI의 계산·요약은 **표본 검증**(한두 행 직접 확인). 큰 표는 필요한 범위·요약 위주로.

## 활용 사례

- **콘텐츠 운영자**: 카드뉴스 텍스트 Gem + 이미지 파이프라인 → 주간 세트를 반나절에.
- **소상공인**: 월 매출 시트 분석 → 인사이트 3줄 → 다음 달 전략.
- **기획자**: 설문 응답을 Fill with Gemini로 자동 분류 → 요약.

## 자주 막히는 점 & 해결

- Gem이 지시를 안 따름 → 섹션화 + 예시 1개, 핵심 규칙을 앞에.
- 엉뚱한 자료 인용 → "첨부 지식 우선, 없으면 추측 금지".
- 이미지 톤 제각각 → 스타일 가이드 문구 고정, "이전과 같은 스타일로".
- 데이터 결과 의심 → 한 행 검증, 범위 좁혀 재질문.

## 실습 미션 ✍️

**미션 1 — 내 첫 Gem**: 반복 업무용 Gem(이름·지시·지식) 저장 후 일반 대화와 비교.

**미션 2 — 톤 통일 이미지**: 스타일 가이드 문구로 같은 톤 이미지 2장.

**미션 3 — Sheets 분석**: Ask Gemini로 추세 3가지 + Fill with Gemini로 한 열 분류 + 한 행 검증.

> 한 줄 정리: 중급은 **Gems로 비서를 만들고, 모듈화하고, 이미지 파이프라인·Sheets의 Ask/Fill Gemini로 데이터 작업을 루틴화**하는 단계입니다. 다음 단계(고급)에서는 **NotebookLM 지식망**과 **Apps Script 자동화**로.
