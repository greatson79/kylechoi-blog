> 고급까지 '도는 자동화'를 만들었습니다. 심화에서는 여러 AI가 **릴레이로 협업**(4단계)하게 만들고, 결과를 **대시보드·웹으로 배포**(5단계)해 '나만의 작은 서비스'로 완성합니다.
>
> 대상: 개인 무료 Gemini. 일부는 조직 맥락이라 **개인 가능 범위 + 조직 확장**으로 구분. ※ 2026년 6월 기준, 구글 공식 문서 근거.

## A. 멀티에이전트 릴레이 협업망 (4단계)

### 4.1 역할 분담형 프롬프트 체이닝 — 실전

하나의 AI에게 다 시키지 말고, **역할이 다른 여러 Gem이 이어달리기**합니다.

> [기획 Gem] → [비판적 검토 Gem] → [최종 편집 Gem]

각 Gem 지시문 예시(복붙):

```text
[기획 Gem]
당신은 콘텐츠 기획자입니다. 주어진 주제로 구조(제목·소제목·핵심 메시지)와 초안을 만듭니다.
독자: ___. 톤: ___.
```

```text
[검토 Gem]
당신은 까다로운 편집장입니다. 받은 초안의 약점·누락·사실 위험·논리 비약을 항목으로 지적하고,
각 항목에 구체적 개선안을 답니다. 칭찬은 생략하고 개선점만.
```

```text
[편집 Gem]
당신은 카피 에디터입니다. 초안과 검토의견을 받아 반영하고, 톤·길이·형식을 다듬어 최종본을 만듭니다.
변경 요약 3줄을 끝에 붙입니다.
```

각 출력이 다음 입력이 됩니다. 역할 분담은 한 AI가 자기 결과를 무비판적으로 쓰는 문제를 줄입니다.

### 4.2 시트 기반 칸반(Kanban) 파이프라인 — 따라하기

1. 시트 열: `아이템 | 원본 | 기획초안 | 검토의견 | 최종본 | 상태`.
2. 각 행이 한 작업물. 왼→오로 이동하며 각 단계 Gem이 가공.
3. '상태' 열에 `대기/진행/완료` → 칸반처럼 한눈에.

> ⚠️ 완전 자동 릴레이는 Apps Script가 필요해 난이도가 있습니다. **개인 무료에선 '반자동'**: 각 단계는 해당 Gem에 복사-붙여넣기, 시트로 **상태만 관리**해도 강력합니다. 자동 전달은 고급 3.3(Apps Script)을 점진 결합.

## B. 노코드 대시보드 구축 및 배포 (5단계)

### 5.1 Looker Studio 실시간 시각화 — 따라하기

**Looker Studio**(무료)에 정리된 Google Sheets를 연결해 실시간 차트를 만듭니다.

- **쉬운 방법(시트에서)**: Sheets → **확장 프로그램(Extensions) → Looker Studio → 새 보고서 만들기** → **만들기(Create)**.
- **데이터 소스로 시작**: Looker Studio → **만들기 → 데이터 소스 → Google Sheets** → 스프레드시트·워크시트 선택 → **CONNECT** → 측정기준(녹색 칩)·측정항목(파란 칩)을 차트에 끌어다 구성.
- **데이터 준비 규칙(중요)**: 표 형식, 병합 셀 금지, **헤더 한 줄**, 한 열은 같은 타입, 날짜는 날짜 형식.

설계 원칙: 목적·청중 우선, 정보 과다 금지, 한 차트 한 메시지.

### 5.2 Google Sites 사내 포털 배포 — 따라하기

**Google Sites**(무료) 노코드 웹빌더:

1. sites.google.com에서 새 사이트.
2. **삽입(Insert)**으로 Looker 대시보드·문서 임베드, 매뉴얼 텍스트, 용도별 Gem 링크 추가.
3. **게시(Publish)** → 링크 공유.

> 🏢 **조직 확장(참고)**: 사내 전용 배포·조직 공유 Gem·도메인 제한 공유는 **Workspace(조직)** 기능. 개인 무료에선 Looker·Sites 자체 사용 + 링크 공유는 가능하되 조직 전용 권한·관리는 제한. 도입 시 관리자와 권한 설계.

## C. 캡스톤 — 나만의 미니 AI 서비스 🏁

내 반복 업무 하나를 1~4단계로 엔드투엔드 구성 + 배포:

1. **입력·기초(1·2)**: 4요소 프롬프트 + 전용 Gem(들).
2. **지식·자동화(3)**: NotebookLM 근거 + (가능하면) Apps Script.
3. **협업·파이프라인(4)**: 역할 분담 Gem 릴레이 + 시트 칸반.
4. **시각화·배포(5)**: Looker 대시보드 + Sites 포털.

**산출물**: ① 워크플로우 설계도 ② 도구·역할 표 ③ 안전·권한 점검 ④ '잘 도는지' 기준.

**예시(콘텐츠 운영)**: 주제 입력 → [기획]→[검토]→[편집] 릴레이(칸반 시트로 상태) → 발행 성과를 시트 기록 → Looker 대시보드 → Sites 포털에 대시보드+Gem 링크 게시.

## 실습 미션 ✍️

- **미션 1 — 릴레이 설계**: 3역할 Gem 지시문 각 2~3줄(위 예시 참고).
- **미션 2 — 칸반 시트**: 단계 열(4~5개)을 만들고 아이템 1개를 끝까지 이동(반자동).
- **미션 3 — 대시보드+포털**: 시트로 Looker 차트 1개(데이터 준비 규칙) → Sites에 임베드·링크.
- **미션 4 — 캡스톤**: 4요소를 한 장 흐름도 + 권한·안전 점검표.

> 한 줄 정리: 심화는 **역할 Gem 릴레이 + 시트 칸반 + Looker 대시보드 + Sites 배포**로 '나만의 작은 AI 서비스'를 완성하는 단계입니다. 이로써 Gemini 트랙(온보딩 → 비서 → 지식·자동화 → 멀티에이전트 → 배포)을 마칩니다.
