## 1위와 6위의 거리가 12점이다

2026년 6월 17일 갱신된 코딩 에이전트 벤치마크 Terminal-Bench 2.1을 보면, 모델 단독 점수가 좁은 띠 안에 몰려 있다. Claude Fable 5가 80.52%로 가장 높고, GPT-5.5 76.40%, Gemini 3.5 Flash 74.16%, Claude Opus 4.8 71.91%, Gemini 3.1 Pro Preview 70.79%, Claude Opus 4.7 68.54% 순이다(Vals AI, Terminal-Bench 2.1, 2026-06-17). 89개 터미널 과제를 pass@1로, Terminus 2라는 공통 하니스로 측정한 결과다. 1위와 6위의 차이가 약 12점에 불과하다.

게다가 1위 숫자에는 단서가 붙는다. 벤치마크 사이트는 "Fable 5의 결과는 모델이 작업을 거부할 때 Claude Opus 4.8을 폴백으로 사용해 측정했다"고 명시한다(Vals AI, 2026-06-17). 즉 가장 높은 점수조차 단일 모델이 아니라 모델을 감싼 실행 장치 — 하니스(harness) — 의 산물이라는 뜻이다.

## 같은 모델, 다른 하니스, 다른 점수

이 한 줄의 각주가 2026년 코딩 에이전트 경쟁의 성격을 압축한다. 모델 가중치가 같아도, 도구 호출·재시도·거부 처리·컨텍스트 관리를 어떻게 짜느냐에 따라 결과가 달라진다. 실제로 같은 벤치마크를 에이전트 제품별 하니스 기준으로 다시 집계하면 동일 모델의 점수가 또 움직인다. 그래서 "어느 모델이 제일 똑똑한가"라는 질문은 "어느 에이전트가 그 모델을 가장 잘 부리는가"로 바뀐다.

Cursor가 5월 18일 내놓은 Composer 2.5는 이 방향을 노골적으로 보여준다. Cursor는 이 모델이 "Composer 2와 동일한 오픈소스 체크포인트, 즉 Moonshot의 Kimi K2.5 기반"이라고 공식 블로그에서 밝혔다(Cursor, 2026-05-18). 자체 프런티어 모델을 새로 훈련한 게 아니라, 공개 체크포인트를 가져와 긴 작업·도구 사용에 맞게 다듬은 것이다. 가격은 표준 티어에서 입력 100만 토큰당 $0.50, 출력 $2.50로 책정했다(Cursor, 2026-05-18). 경쟁의 축이 "더 큰 모델"이 아니라 "값싸게 잘 부리는 실행 계층"으로 이동한 사례다.

## 과금이 '좌석'에서 '소비량'으로

무게중심 이동은 가격표에서도 드러난다. GitHub는 2026년 6월 1일부터 Copilot 전 플랜을 사용량 기반 과금으로 전환했다(The GitHub Blog, 2026-06-01). 모델별 공시 API 요율에 따라 입력·출력·캐시 토큰 사용량으로 비용을 산정하는 방식이다. 코드 완성과 Next Edit Suggestions는 모든 플랜에 그대로 포함돼 크레딧을 소모하지 않지만, 에이전트형 워크플로와 코드 리뷰 같은 기능은 크레딧을 쓴다. 플랜 가격 자체는 Pro $10, Pro+ $39, Business $19/사용자, Enterprise $39/사용자로 유지하되, 각 플랜에 동일 금액의 월 크레딧을 포함시켰다(The GitHub Blog, 2026-06-01).

핵심은 단가표가 아니라 발상의 전환이다. "사람 수 × 정액"으로 팔던 개발 도구가 "실제로 모델을 얼마나 돌렸는가"로 값을 매기기 시작했다. 이는 산업 분석과도 맞물린다. 인공지능신문이 인용한 딜로이트 전망은 2026년을 두고 "승부는 더 뛰어난 모델이 아니라 AI를 규모 있게 운영하는 능력이 가른다"고 정리한다. 같은 전망은 에이전틱 AI 시장이 2026년 약 85억 달러에서 2030년 약 350억 달러로 커지고, 2026년 AI 컴퓨팅 파워의 약 3분의 2가 추론(inference)에 쓰일 것으로 본다(인공지능신문, 딜로이트 전망 인용). 과금이 소비량으로 옮겨가는 흐름과 추론 비용이 중심이 되는 흐름은 같은 동전의 양면이다.

## 한계와 주의

다만 벤치마크 숫자를 과신하면 안 된다. Terminal-Bench 2.1은 89개 과제라는 한정된 표본이고, 버전 2.1은 2.0보다 어렵게 설계돼 이전 버전 점수와 직접 비교할 수 없다. 하니스·폴백 같은 측정 조건이 순위를 흔드는 만큼, "1위 모델"이라는 표현은 측정 방식까지 함께 읽어야 의미가 산다. 가격 역시 토큰 단가가 곧 총비용은 아니다. 에이전트가 과제 하나에 토큰을 얼마나 태우는지에 따라 체감 비용은 크게 달라지므로, 단가가 낮다고 저렴한 도구라고 단정할 수 없다. 시장 규모·투자 비중 같은 전망치는 분석기관(딜로이트)의 추정이며 실제와 어긋날 수 있다. 이 글의 수치는 모두 1차·권위 출처에서 직접 확인한 범위로 한정했고, 일부 2차 매체가 언급한 추가 수치와 지정학 주장은 1차 확인이 안 돼 의도적으로 제외했다.

## 한 줄 정리

모델 성능이 좁은 띠 안으로 수렴하는 2026년, 코딩 에이전트의 승부는 "누가 더 똑똑한 모델을 가졌나"에서 "누가 모델을 더 잘 부리고, 더 합리적으로 값을 매기는가"로 옮겨가고 있다.
